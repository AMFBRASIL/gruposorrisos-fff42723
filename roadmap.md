# Roadmap — Grupo Sorrisos ERP Multifiliais (dados de demonstração)
- [x] Novo processo de pedidos — manual/CSV, conciliação, revisão e fornecedor definido; fluxo demonstrativo verificado no navegador
- [x] Área interna por fornecedor e respostas de preços versionadas, conferência e aprovação de compra
- [ ] Área externa real de fornecedores — Cloud e estrutura de acesso preparados; depende de autorização da fase real e contas vinculadas a fornecedores; não disponível nesta entrega
- [x] Padronizar todos os campos monetários com máscara de reais brasileira e validar digitação/salvamento
- [x] Onda 1 — Estoque básico
- [x] Fase 2 — Filiais, depósitos, usuários por filial, perfis e permissões, seletor de filial
- [x] Fase 3 — Telas de estoque filtradas por filial
- [x] Fase 4 — Pedidos de materiais (lista/kanban, wizard, fluxo completo) + Centro de Distribuição
- [x] Fase 5 — Transferências movimentam saldo na origem/destino
- [x] Fase 6 — Compras/fornecedores/cotações, inventário por filial, reposição automática
- [x] Fase 7 — Notificações de pendências no sino
- [x] Fase 8 — Testes automáticos das regras de pedido e acesso
- [ ] Futuro — dados reais (Lovable Cloud), dashboards por perfil, cartões de pedido no Kanban

- [x] Pedidos e telas de estoque modernizadas (indicadores, gráficos, botão Novo + wizard grande com imagem)
- [x] Inventário em wizard; movimentação multi-itens
- [ ] Migrar demais modais antigos (Compras, Filiais) para o WizardShell
- [x] Estoque avançado — reposição com pedidos/compras e prevenção de duplicados
- [x] Leitura de códigos por câmera e leitor em movimentações, inventários e recebimento (câmera física não verificada)
- [x] Separação FEFO e baixa de lotes na expedição, preservando lotes no recebimento
- [x] Consumo por procedimento com ficha de materiais e baixa agrupada
- [x] Previsão de cobertura, itens sem giro e classificação ABC
- [x] Aprovação de ajustes elevados com histórico e limite configurável (R$ 500 inicial demonstrativo)
- [x] Alertas por filial e resumo de e-mail simulado (sem envio real, conforme escopo demo)
- [x] Testes das regras e verificação de consumo, reposição, inventário aprovado, códigos e resumo no navegador
